# Namma Raste Health

## Problem Statement
Many roads and public areas suffer from poor cleanliness, garbage dumping, unhealthy surroundings, and lack of awareness about public hygiene. These issues affect public health and create an unsafe environment for citizens.

## Project Description
Namma Raste Health is a community-focused application designed to improve public health and cleanliness awareness. The project helps users report unhealthy road conditions, garbage issues, water leakage, and sanitation problems in their area.

The platform encourages citizens to actively participate in maintaining clean and healthy surroundings by providing an easy reporting and monitoring system.

## Features
- Report road and sanitation issues
- Upload images of unhealthy areas
- Track reported complaints
- Increase public health awareness
- User-friendly interface
- Quick complaint submission system

## Technologies Used
- Android Studio
- Kotlin
- Firebase
- XML
- GitHub

## How It Works
1. User opens the application
2. Selects the issue category
3. Uploads image and description
4. Complaint gets submitted
5. Authorities/community can review and take action

## Advantages
- Promotes public cleanliness
- Helps maintain healthy surroundings
- Encourages community participation
- Easy and fast reporting system
- Supports smart city initiatives

## Future Enhancements
- Live complaint tracking
- AI-based issue detection
- GPS location integration
- Notification system
- Admin dashboard

## Conclusion
Namma Raste Health aims to create cleaner, healthier, and safer surroundings by connecting citizens with community health initiatives through technology.
